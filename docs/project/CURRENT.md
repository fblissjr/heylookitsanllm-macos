# Current State (`heylookitsanllm-macos`)

Last updated: 2026-11-18 (`main`, audited against `heylookitsanllm` `v2.0.251`)

This document is the **honest status baseline** of `heylookitsanllm-macos` (`Swift 6.4` in `v6` language mode, targeting `macOS 27.2+` and `iOS 27.2+`, running on `27.2.1` hosts with `#available(macOS 27.3, iOS 27.3, *)` guards). Earlier revisions marked every subsystem `SOLID` and claimed complete parity; this reset replaces those claims with verified code status and maps the remediation work in [TODO.md](./TODO.md) (**Phases 16A–16E**).

> **Build Dependencies Reality Check (`Package.swift`):** Remote SwiftPM dependencies are `mlx-swift`, `mlx-swift-lm`, and `swift-transformers` (under `HEYLOOK_ENABLE_NATIVE_MLX=1` or Xcode) plus `coreai-models` (under `HEYLOOK_ENABLE_COREAI=1`). Phantom libraries (`hummingbird`, `argmax-oss-swift`) are **not** dependencies of this package.
